# คำศัพท์บนหน้าจอ (UI glossary) — ใช้คำเดียวกันทั้งระบบ

> รอบ 252 WP-13 M (audit 249 D §11 M) · ตัวตรวจ: `python3 tools/ui_glossary_check.py` (ratchet ต่อไฟล์ — คำต้องห้ามในข้อความที่ผู้ใช้เห็นห้ามเพิ่ม)
> ผู้อ่านหน้าจอคือเจ้าของร้าน/นักบัญชี/ลูกค้าปลายทาง — ไม่ใช่นักพัฒนา · ศัพท์อังกฤษใส่ในวงเล็บต่อท้ายคำไทยได้เมื่อช่วยค้นหา (เช่น "ส่งสำเนาลับ (BCC)")

## คำต้องห้าม → คำที่ใช้แทน (ตัวตรวจนับคำซ้ายมือ)

| ห้ามใช้ (ผู้ใช้เห็น) | ใช้แทน | หมายเหตุ |
| --- | --- | --- |
| fallback | "ใช้ … แทน" / "ถ้าไม่มี ระบบจะ …" | เช่น "ระบบจะส่งผ่านเซิร์ฟเวอร์อีเมลส่วนกลางแทน" |
| push (แจ้งเตือน) | ส่งแจ้งเตือน | |
| Trigger | ส่งเมื่อ (เหตุการณ์) / เหตุการณ์ | หน้าตารางส่งอีเมล |
| Default-deny | เริ่มจากปิดทุกช่อง | |
| Sys / System (ช่องแจ้งเตือน) | กระดิ่ง / กระดิ่งในระบบ | |
| Mail / Email (ช่องแจ้งเตือน) | อีเมล | ชื่อสิทธิ์ทางเทคนิค เช่น `Mail.Send` ในคู่มือตั้งค่า Microsoft อยู่ใน baseline |
| L1 / L2 / L4 (ระดับงานภายใน) | ไม่แสดง — อธิบายสิ่งที่ผู้ใช้ทำได้แทน | ชื่อเฟสงานภายในไม่ใช่ศัพท์ของผู้ใช้ |
| workspace | บริษัท | |
| invite | เชิญ | |
| Portal | พอร์ทัลลูกค้า / พอร์ทัลผู้ขาย | |
| Session (หมดอายุ) | หมดเวลาการเข้าสู่ระบบ — กรุณาเข้าสู่ระบบใหม่ | |

## คำที่ต้องใช้ให้ตรงกัน (ไม่มีตัวตรวจ — ตรวจตอนรีวิว)

| เรื่อง | คำเดียวที่ใช้ | ไม่ใช้ |
| --- | --- | --- |
| สิ่งที่ลูกค้าซื้อ | **แพ็กเกจ** | Plan · แผน · Subscription |
| แพ็กเกจหลายบริษัทของผู้ใช้ | **License หลายบริษัท** (สั้น: License) | Account Plan · User Plan |
| บริษัทจ่ายเอง | **จ่ายแพ็กเกจเอง** | Company Plan · subscription แยก |
| ส่งเอกสารให้ลูกค้าโดยระบบ | **ส่งอัตโนมัติ** | auto-send · Autopilot (ชื่อฟีเจอร์ภายใน) |
| รายการเกิดซ้ำ | **รายการประจำ** | Recurring · รายการที่เกิดซ้ำ |
| สมุดรายวัน/JE | **รายการบัญชี** (ในข้อความทั่วไป) | JE (ยกเว้นหน้าบัญชีที่ผู้ใช้เป็นนักบัญชี) |
| ใบสรุปยอดลูกค้า | **ใบแจ้งยอด** | Statement |
| สถานะ enum (Active/Trial/Draft …) | ป้ายไทยจากเซิร์ฟเวอร์ (`*Label` ใน DTO) | ชื่อ enum ดิบ · ตาราง enum→ไทยใน JS (F2 ข้อ 5) |

## ป้ายที่มาของคำแนะนำ

`Layout.suggestLabel(resp)` เท่านั้น — "🤖 AI แนะนำ" เมื่อเซิร์ฟเวอร์ตอบ `usedAi: true` · ไม่งั้น "⚙️ ระบบแนะนำ" (`tools/ai_label_literal_check.py`)
