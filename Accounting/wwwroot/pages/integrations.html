API Integration Guide

คู่มือเชื่อมต่อ API สำหรับนักพัฒนา

Authentication

ส่ง API Key ผ่าน header X-Integration-Key ในทุก request

X-Integration-Key: int_xxxxxxxxxxxxxxxx
Content-Type: application/json

Inbound Endpoints (ส่งข้อมูลเข้า Next Acc)

POST /api/integration/customers       - Sync ข้อมูลลูกค้า/ผู้จำหน่าย
POST /api/integration/invoices        - สร้างใบแจ้งหนี้/ใบกำกับภาษี
POST /api/integration/payments        - บันทึกการชำระเงิน
POST /api/integration/expenses        - บันทึกค่าใช้จ่าย
POST /api/integration/credit-notes    - สร้างใบลดหนี้
POST /api/integration/debit-notes     - สร้างใบเพิ่มหนี้
POST /api/integration/products        - Sync สินค้า/บริการ
POST /api/integration/journals        - บันทึกบัญชีโดยตรง
POST /api/integration/daily-summary   - สรุปรายวัน (Auto Journal)
POST /api/integration/batch           - Batch import หลายรายการ

Outbound Endpoints (ดึงข้อมูลจาก Next Acc)

GET /api/integration/documents        - ดึงข้อมูลเอกสาร (ใบแจ้งหนี้, ใบเสร็จ, etc.)
GET /api/integration/contacts          - ดึงข้อมูลลูกค้า/ผู้จำหน่าย
GET /api/integration/payments-list     - ดึงข้อมูลการชำระเงิน
GET /api/integration/account-balances  - ดึงยอดคงเหลือบัญชี

# Query Parameters:
?fromDate=2024-01-01&toDate=2024-12-31&status=Approved&type=Invoice&page=1&pageSize=50

{

  "description": "สรุปรายรับประจำวัน",
  "lines": [
    { "category": "REVENUE", "description": "รายได้จากการขาย", "amount": 45000 },

  ]

หมายเหตุ: category ใน daily-summary ต้องตรงกับ Account Mapping ที่ตั้งค่าไว้ (tab Account Mapping)
