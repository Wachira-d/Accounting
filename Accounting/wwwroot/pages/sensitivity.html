🔐 สิทธิ์ดูเอกสารลับ

กำหนดว่าตำแหน่งใดในบริษัทจะเห็นเอกสารแต่ละประเภทได้ — เอกสารที่ถูกซ่อนจะยังปรากฏใน API แต่จะมี flag isRedacted: true เพื่อให้ระบบที่เชื่อมต่อรู้ว่ามีเอกสารถูกซ่อนและไปจัดการต่อเอง · เจ้าของบริษัทเห็นทุกอย่างเสมอ ไม่สามารถปิดได้

💡 API integration: ระบบที่เรียก API ด้วย token ของผู้ใช้ที่ไม่มีสิทธิ์ จะได้รับ { isRedacted: true, redactedReason: "..." } แทนข้อมูลจริง · endpoint /api/companies/{cid}/payroll/runs จะตอบ 403 พร้อม body ที่มี kind + requiredPermission
