📋 Record of Processing Activity (RoPA)

บันทึกกิจกรรมการประมวลผลข้อมูลส่วนบุคคลของบริษัท (ม.39) — PDPC ตรวจจะขอดูตัวนี้

✅ บันทึกความยินยอม (Consent)

บันทึกการยินยอม/ถอนความยินยอมตาม ม.19, 22 — ต้องเก็บหลักฐาน (evidence hash)

💡 ระบบใช้ลำดับเหตุการณ์ — บันทึกผ่าน API ตรง.
ใช้ POST /api/companies/{id}/pdpa/consent + /withdraw เพื่อจัดการ.
UI สำหรับ list ทั้งหมดสามารถ extend ได้ใน sprint ถัดไป (ขอบเขตของ MVP).

🚨 เหตุการณ์ข้อมูลรั่วไหล (Breach)

ม.37(4) — ต้องแจ้ง PDPC ภายใน 72 ชั่วโมงนับจากตรวจพบ

⏰ Alerts — ใกล้ครบ 72 ชม. หรือเกินกำหนด

👁️ PII Access Log (ม.37(4))

บันทึก event การเข้าถึงข้อมูล PII (เช่น HR เปิดดูเลขบัตรประชาชน) — เก็บ ≥ 1 ปี

💡 ระบบบันทึก log อัตโนมัติเมื่อ caller เรียก IPdpaService.LogPiiAccessAsync(...).
การเชื่อมโยงไปยัง PayrollController/HR endpoints (เพื่อ log เมื่อ user เปิดดู CitizenId) ทำได้ใน sprint ถัดไป
— backend service พร้อมรับ event แล้ว.
