Authentication

ทุก request ต้องส่ง API Key ผ่าน header X-Integration-Key หรือ Authorization: Bearer {key}

API Key จะระบุตัวตนว่าเป็น Integration ของบริษัทไหน โดยไม่ต้องส่ง companyId เอง

curl -X POST https://your-domain/api/integration/customers \
  -H "X-Integration-Key: int_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"name": "บริษัท ตัวอย่าง จำกัด"}'

วิธีรับ API Key

  1. เข้าเมนู เชื่อมต่อระบบ (Settings > Integration)
  2. กด "+ เพิ่มระบบ" กรอกชื่อและประเภท
  3. ระบบจะแสดง API Key และ Secret Key (แสดงครั้งเดียว)
  4. เก็บ API Key ไว้ส่งใน header ทุก request

Security

  • API Key ถูก hash ด้วย BCrypt ก่อนเก็บในฐานข้อมูล
  • Secret Key ใช้สำหรับ HMAC-SHA256 signature verification (Webhook)
  • สามารถ regenerate API Key ใหม่ได้ (key เดิมจะใช้ไม่ได้ทันที)
  • มี Rate Limiting ป้องกัน abuse (ค่าเริ่มต้น 60 req/min)

Quick Start

ขั้นตอนเชื่อมต่อ 3 ขั้นตอน

1. สร้าง Integration

เข้า Settings > เชื่อมต่อระบบ > สร้าง integration ใหม่ รับ API Key

2. ตั้งค่า Account Mapping

เลือก template ตามธุรกิจ หรือตั้งค่า mapping เอง (External Category → ผังบัญชี)

3. เรียก API

ส่ง request ผ่าน API พร้อม API Key ในทุก request ระบบจะบันทึกและสร้างบัญชีอัตโนมัติ

Base URL

https://your-domain/api/integration/

ไม่ต้องระบุ companyId ใน URL — ระบบจะระบุจาก API Key อัตโนมัติ

Error Codes

HTTP Codeสถานะคำอธิบาย
200OKสำเร็จ
201Createdสร้างข้อมูลสำเร็จ
400Bad Requestข้อมูลไม่ถูกต้อง — ตรวจสอบ request body (เช่น field ที่ขาด, format ไม่ถูก)
401UnauthorizedAPI Key ไม่ถูกต้อง หรือไม่ได้ส่ง header X-Integration-Key
404Not Foundไม่พบข้อมูลที่อ้างอิง (เช่น invoice ที่ระบุ, ผังบัญชีที่ระบุ)
422Unprocessableข้อมูลผ่าน validation แต่ประมวลผลไม่ได้ (เช่น ยอดเดบิต≠เครดิต)
429Too Many Requestsเกิน rate limit — ลดความถี่ในการเรียก
500Server Errorข้อผิดพลาดภายในระบบ — ติดต่อ admin

Rate Limiting

ค่าเริ่มต้น: 60 requests/minute ต่อ Integration (ปรับได้ในหน้าตั้งค่า)

เมื่อเกิน limit จะได้ HTTP 429 — ใช้ exponential backoff (รอ 1s, 2s, 4s, ...)

สำหรับ batch import ใช้ POST /api/integration/batch แทนการเรียกทีละรายการ

Webhooks

เมื่อเปิดใช้ Webhook ระบบจะส่ง HTTP POST ไปยัง URL ที่กำหนดเมื่อมีเหตุการณ์เกิดขึ้น

Signature Verification (HMAC-SHA256)

ทุก webhook request จะมี header X-Webhook-Signature สำหรับยืนยันความถูกต้อง

// Node.js: Verify webhook signature
const crypto = require('crypto');
const secretKey = 'your-secret-key'; // จาก Integration settings
const payload = JSON.stringify(req.body);
const signature = crypto
  .createHmac('sha256', secretKey)
  .update(payload)
  .digest('hex');
const isValid = signature === req.headers['x-webhook-signature'];
# Python: Verify webhook signature
import hmac, hashlib
secret_key = b'your-secret-key'
payload = request.data
expected = hmac.new(secret_key, payload, hashlib.sha256).hexdigest()
is_valid = hmac.compare_digest(expected, request.headers['X-Webhook-Signature'])

import requests

API_KEY = 'int_xxxxxxxxxxxxxxxx'
BASE = 'https://your-domain/api/integration'
HEADERS = {'X-Integration-Key': API_KEY, 'Content-Type': 'application/json'}

# สร้างใบแจ้งหนี้
res = requests.post(f'{BASE}/invoices', json={
    'customerName': 'บริษัท ตัวอย่าง จำกัด',
    'documentDate': '2024-04-02',
    'lines': [{'itemName': 'ค่าบริการ', 'quantity': 1, 'unitPrice': 10000}]
}, headers=HEADERS)
print(res.json()['documentNumber'])

# Batch import
res = requests.post(f'{BASE}/batch', json={
    'customers': [{'name': 'ลูกค้า A', 'taxId': '0123456789012'}],
    'invoices': [{
        'customerName': 'ลูกค้า A',
        'documentDate': '2024-04-02',

    }]

batch = res.json()
print(f'Success: {batch["successCount"]}/{batch["totalProcessed"]}')

Pagination

Outbound endpoints (GET) รองรับ pagination ผ่าน query parameters

ParamDefaultคำอธิบาย
page1หน้าที่ต้องการ (เริ่มจาก 1)
pageSize50จำนวนรายการต่อหน้า (max 100)
// Response format
{
  "items": [...],          // รายการในหน้านี้
  "totalCount": 500,       // จำนวนทั้งหมด
  "page": 1,               // หน้าปัจจุบัน
  "pageSize": 50,           // จำนวนต่อหน้า
  "totalPages": 10          // จำนวนหน้าทั้งหมด
}

// วนดึงทุกหน้า:
let page = 1;
do {
  const res = await fetch(`${BASE}/documents?page=${page}&pageSize=50`, ...);
  const data = await res.json();
  // process data.items...
  page++;
} while (page <= data.totalPages);
