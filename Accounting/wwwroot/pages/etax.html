ยกเลิก e-Tax ที่ส่งกรมสรรพากรแล้ว

ระบบนี้ไม่ได้ส่งคำยกเลิกถึงกรมสรรพากร — ยกเลิกที่ระบบ e-Tax ของกรมสรรพากร/ผู้ให้บริการก่อน แล้วแนบไฟล์หลักฐานการยกเลิกที่นี่ · สถานะในระบบจะแสดงว่า “ยกเลิกในระบบนี้” (ไม่ใช่คำยืนยันจากกรมสรรพากร)

ตั้งค่า e-Tax Invoice

          
        

        

          

          

          
ขั้นตอนการตั้งค่าสำหรับ Production

          

            
1. ใบรับรองดิจิทัล (Digital Certificate)

            
    
              
  • ซื้อ e-Tax Certificate จาก CA ที่ ETDA รับรอง (TOT, CAT, INET)
    • 
              
  • ได้ไฟล์ .p12 หรือ .pfx
    • 
              
  • ตั้งค่า Etax:CertificatePath ใน appsettings.json
    • 
              
  • ตั้งค่า Etax:CertificatePassword
    • 
            

            
2. สมัคร RD e-Tax API

            
    
              
  • สมัครที่ etax.rd.go.th
    • 
              
  • ได้ API Key + Secret
    • 
              
  • ตั้งค่า Etax:RdApiKey และ Etax:RdApiSecret
    • 
            

            
3. ทดสอบ

            
    
              
  • เปิด Test Mode: Etax:RdTestMode = true
    • 
              
  • ทดสอบสร้าง + ลงนาม + ส่ง กับ RD Test Server
    • 
              
  • เมื่อพร้อม เปลี่ยน RdTestMode = false
    •
