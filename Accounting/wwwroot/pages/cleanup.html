⚠️ หน้าตั้งต้นใหม่ — สำหรับเจ้าของบริษัทเท่านั้น ใช้ก่อนเริ่มใช้งานจริง (ลบข้อมูลทดสอบ) เท่านั้น
การลบไม่สามารถย้อนกลับได้จากหน้านี้ ข้อมูล soft-delete เก็บไว้ใน DB แต่จะไม่แสดงในระบบ — กู้คืนต้องติดต่อแอดมินผ่านการรัน SQL

🧹 เริ่มต้นใหม่ (Bulk Cleanup)

ลบข้อมูลทั้งหมดของบริษัท เพื่อเริ่มใช้งานจริงด้วยข้อมูลสะอาด — Owner เท่านั้น

📊 ข้อมูลปัจจุบัน
เอกสาร (Documents)-
สมุดรายวัน (Journal Entries)-
การชำระเงิน (Payments)-
POS Orders-
ผู้ติดต่อ (Contacts)-
สินค้า (Products)-
สินทรัพย์ถาวร (Fixed Assets)-
งวดบัญชี (Fiscal Periods)-

🗑️ ลบเฉพาะ Transactions

ลบ Documents / Journal Entries / Payments / POS Orders / Stock Movements ทั้งหมด
คงไว้: Master data (สินค้า / ผู้ติดต่อ / ผังบัญชี / งวดบัญชี)
เหมาะกับการ "เริ่มปีใหม่" หรือลบข้อมูลทดสอบก่อนใช้จริง

🧹 ลบ Master Data

ลบผู้ติดต่อ / สินค้า · ใช้ได้หลังจาก transactions ถูกลบหมดแล้ว
คงไว้: ผังบัญชี / งวดบัญชี / ตั้งค่าบริษัท
