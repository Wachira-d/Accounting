การแจ้งเตือน

Notification Engine — ตั้งค่าใครได้รับแจ้งเตือนผ่าน System / Email / LINE สำหรับเหตุการณ์ใด

Default-deny: ทุกช่องเริ่มจาก "ปิด" — ติ๊กเฉพาะ event × ผู้รับ × ช่องทาง ที่ต้องการให้แจ้งจริง ๆ
ที่นี่คุณ ปิด ช่องทางแจ้งเตือนของตัวเองได้ (เช่น "ไม่อยากรับ Email สำหรับเหตุการณ์ลา ใช้ LINE อย่างเดียวพอ"). ไม่สามารถ เปิด ช่องที่บริษัทยังไม่ได้เปิดให้ — ติดต่อ Admin
ผูก LINE User ID ของคุณ → ระบบจะ push แจ้งเตือนเข้า LINE ส่วนตัว (ไม่ใช่ group). ถ้ายังไม่ผูก ระบบจะ fallback ไป System / Email อัตโนมัติ
หา ID ได้จาก: เพิ่มบอทเป็นเพื่อน → ทักไปบอท → admin webhook จะ log ID ให้ (หรือใช้ LINE Developers Console)
