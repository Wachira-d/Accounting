🏢 สาขาและคลังของเว็บนี้

ใบขาย/ใบมัดจำ/ใบเสนอราคาจากออเดอร์และการจองของเว็บนี้ออกในนามสาขาที่เลือก (รหัสสาขาบนใบกำกับ §86/4) — ไม่เลือก = สำนักงานใหญ่ (เหมือนเดิม) · เลขที่เอกสารรันต่อเนื่องชุดเดียวของบริษัท · มีผลกับใบใหม่เท่านั้น

🔒 ข้อมูลส่วนบุคคล (PDPA)

ช่องยินยอม + ลิงก์นโยบายแสดงบนฟอร์มสั่งซื้อ · จอง · ติดต่อ — ลูกค้าติ๊กแล้วระบบบันทึกหลักฐานความยินยอม (เวอร์ชันตามข้อความที่แสดง) · ติ๊ก "บังคับ" ⇒ ไม่ติ๊กส่งไม่ได้ (ตรวจที่เซิร์ฟเวอร์)

ลิงก์นโยบาย/ข้อกำหนดบนฟอร์มและท้ายเว็บ ตั้งที่หัวข้อ 📜 นโยบายความเป็นส่วนตัว & ข้อกำหนดของร้าน ด้านล่าง

📜 นโยบายความเป็นส่วนตัว & ข้อกำหนดของร้าน

ร้านเป็นผู้ควบคุมข้อมูลส่วนบุคคลของลูกค้าที่สั่งซื้อ/จอง/สมัครสมาชิกผ่านเว็บนี้ (NextAcc เป็นผู้ประมวลผลข้อมูล) — PDPA ม.23 ต้องแจ้งนโยบายก่อนเก็บข้อมูล · ลิงก์แสดงท้ายเว็บทุกหน้า · บนช่องยินยอมของฟอร์มสั่งซื้อ/จอง/ติดต่อ · หน้าสมัครสมาชิก · แบนเนอร์คุกกี้ · แม่แบบของระบบเติมชื่อร้าน ที่อยู่ อีเมล/เบอร์โทรจากข้อมูลบริษัท/ข้อมูลติดต่อด้านบนให้อัตโนมัติ (เลขผู้เสียภาษีแสดงเฉพาะนิติบุคคล) — ตรวจให้ครบก่อนเผยแพร่เว็บ

👥 จัดสรรผู้ให้บริการ / ห้อง / อุปกรณ์

เปิดแล้ว: กด "เริ่มให้บริการ" ที่หน้าทำงานจะให้เลือกผู้ให้บริการที่ว่าง (ได้หลายคน + แบ่ง % งาน) · มีหน้าสรุปงาน/รายงานผู้ให้บริการ · บริการแต่ละอันเลือกโหมด "ลูกค้าเลือก / ระบบจัดให้ / บังคับระบุ" ได้ในหน้าแก้ไขบริการ · ปิด = ทุกบริการนับความจุของบริการ (ค่าตั้งรายบริการยังเก็บไว้)
รายชื่อผู้ให้บริการ
ตารางงานรายบุคคล (เวลาเข้า-ออก · วันหยุด/ลา) + บริการที่รับได้ — ใช้คำนวณรอบว่างของบริการที่ตั้ง "จัดสรรผู้ให้บริการ"

📝 ข้อมูลที่ลูกค้าต้องกรอกตอนจอง

ชื่อ-นามสกุล บังคับเสมอ (ใช้ออกเอกสาร/เรียกคิว) · ซ่อนทั้งเบอร์และอีเมลพร้อมกันไม่ได้ · พนักงานสร้างการจองเองไม่ผ่านด่านนี้

กำลังโหลด…
ตารางนี้สรุปตามค่าตั้งปัจจุบัน + สถานะจด VAT ของบริษัท (บันทึกแล้วตารางเปลี่ยนตาม) · จังหวะใบกำกับของบริการแบบการันตีตั้งที่หัวข้อ "เวลา/แจ้งเตือน"

💳 การชำระเงินของการจอง (มัดจำ / จ่ายเต็มก่อน)

ลูกค้าเห็นยอดที่ต้องจ่าย + กำหนดเวลา + วิธีชำระ ก่อนกดจอง · หลังจองโอน/สแกน QR แล้วแนบสลิป (ร้านตรวจที่หน้า "การจอง") หรือจ่ายออนไลน์ · เก็บเงินล่วงหน้าได้เฉพาะบริการชนิด "ชำระมัดจำล่วงหน้า (ใบรับมัดจำ)" — ใบรับมัดจำลงวันที่รับเงิน (§78/1) · บริการแต่ละตัวตั้งทับได้ที่ฟอร์มบริการ
ไม่ชำระ/ไม่แนบสลิปในเวลา ⇒ ระบบยกเลิกการจองและปล่อยรอบให้คนอื่น (ไม่เกินเวลานัด) · แนบสลิปแล้วไม่ถูกยกเลิกระหว่างรอร้านตรวจ

ช่องทางรับเงิน

ใช้บัญชีเดียวกับ "ตั้งค่าการรับเงิน" ของคำสั่งซื้อ (แก้ที่นี่ = แก้ที่นั่นด้วย)
ใส่แล้วระบบสร้าง QR ที่มียอดเงินให้ลูกค้าอัตโนมัติ
ค่าธรรมเนียมยกเลิก/คืนมัดจำตามจริงคิดจาก "ยกเลิกฟรีก่อนเวลานัด" + "% ค่าธรรมเนียม" ของแต่ละบริการ (ริบไม่เกินมัดจำ)

1. สิ่งที่เปิดให้จอง

2. ความละเอียดของรอบ

3. ความจุ / การจองซ้อน

1 = ห้ามจองซ้อน · เช่น หมอนวด 3 คน = 3
บริการที่ใส่ชื่อเดียวกันใช้ความจุร่วมกัน (ไม่จองชนกัน)
ปิด = ยอมรับจองซ้อนได้ตามเพดาน (เว้นว่าง = ไม่จำกัด)
มีคนยกเลิก ⇒ ระบบเลื่อนคิวแรกที่ลงได้ขึ้นอัตโนมัติ
ใช้ผู้ให้บริการที่ผูกกับบริการนี้ (ส่วน "ผู้ให้บริการ" ใต้รายการบริการ) · ระบบจัดให้ = คนที่ว่าง + รับงานนี้ได้ + งานน้อยสุดของวัน · ยังไม่ผูกใคร = นับ "รับพร้อมกันต่อรอบ" · คลาสกลุ่ม: นับเป็น "จำนวนคน" + รับพร้อมกัน = ที่นั่งต่อรอบ

4. เวลาทำการรายสัปดาห์ (ไม่ตั้งเลย = ใช้เวลาทำการของเว็บไซต์ · ตั้งแล้วใช้ของบริการนี้ทั้งชุด)

5. วันหยุด / วันพิเศษ

6. จองล่วงหน้า · มัดจำ · ยกเลิก

0 = รับจองเฉพาะวันนี้
ใส่บาทแล้วจะใช้ยอดบาท · ใบมัดจำออกเมื่อเลือก "ชำระมัดจำล่วงหน้า"
ยอดมัดจำใช้ช่อง "มัดจำ (บาท / %)" ด้านบนของบริการนี้ก่อน — ว่างทั้งคู่ = ใช้ยอดตั้งต้นของเว็บ · เก็บเงินล่วงหน้าได้เฉพาะชนิด "ชำระมัดจำล่วงหน้า"
