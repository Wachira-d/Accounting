🧠 Embedded Tesseract (in-process — ไม่ต้องติดตั้งภายนอก)
OCR engine ที่ฝังในแอป .NET โดยตรง (Tesseract NuGet + ImageSharp) — รันใน process เดียวกับ web server ไม่ต้อง Docker, ไม่ต้อง Python, ไม่ต้อง install ของข้างนอก เป็นชั้น fallback สุดท้าย ที่รับประกันว่า OCR จะไม่ล่ม

📋 วิธีติดตั้ง Tesseract language data (ครั้งเดียวตอน deploy)

Tesseract NuGet ติดมากับ project แล้ว แต่ language data files (~10MB สำหรับ Thai+English) ไม่ commit ลง git

วิธี 1: ใช้ helper script (แนะนำ)

./scripts/download-tessdata.sh          # ดาวน์โหลด tessdata_fast (เล็ก, เร็ว)
./scripts/download-tessdata.sh best     # ดาวน์โหลด tessdata_best (แม่นขึ้น แต่ช้ากว่า)

วิธี 2: Manual download

cd Accounting/wwwroot/tessdata
curl -LO https://github.com/tesseract-ocr/tessdata_fast/raw/main/eng.traineddata
curl -LO https://github.com/tesseract-ocr/tessdata_fast/raw/main/tha.traineddata

หลัง install เสร็จ → restart app → log จะแสดง [OCR] Embedded Tesseract initialized — languages: eng+tha

หมายเหตุ: Embedded engine รองรับเฉพาะรูปภาพ (JPG, PNG, BMP, TIFF, WebP) — สำหรับ PDF ต้องใช้ Azure DI หรือ Python service ที่ tier บนๆ

🐍 Python OCR Service (Optional — high-accuracy tier)
External microservice ที่รวม PaddleOCR (PP-OCRv4) + EasyOCR (CRNN) สำหรับ accuracy สูงสุด เป็น optional tier — ถ้าไม่ติดตั้งระบบจะข้ามไป Embedded Tesseract เลย ไม่กระทบการใช้งาน
ยังไม่ทดสอบ
📋 วิธีตั้งค่า Python service (ถ้าต้องการ accuracy สูง)

1. รัน microservice:

cd ocr-service
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8501

2. ใส่ URL ที่ "Python Service URL" ด้านบน (default: http://localhost:8501)

ถ้า Python service ล่ม ระบบจะ fallback ไป Embedded Tesseract อัตโนมัติ — ไม่มี downtime
