# รอบ 277 — เมนูตามสิทธิ์ + คำเชิญเข้าบริษัทโดยไม่ต้องสร้างบริษัท

ความต้องการเจ้าของ (2026-11-20): (1) "ไม่มีสิทธิ์ “ดูแดชบอร์ดภาพรวม” (Reports.Dashboard) … ถ้าสิทธิ์ดูไม่ได้ก็ซ่อนเมนูนั้นไม่ให้เห็นไปเลย" ·
(2) "ส่งเมล์ invite … เหมือนส่งไปให้สร้างบริษัทใหม่ก่อนถึงจะเชิญได้ … ส่งคำเชิญไป กดเชิญ ตรงจัดการทีมก็ยังไม่ขึ้นจนกว่าเขาจะสมัครและกดเชิญใหม่"

> ⚠️ คอมไพล์ + รันเทสต์ที่เกี่ยวข้องในเครื่องนี้แล้ว (.NET 8 + PostgreSQL 16 ฐาน `accounting_test_r277`) · ชุดเต็มรอ CI รวมของผู้ประสานงาน

## 3. ตรวจแล้วไม่ใช่บั๊ก
- เส้นสมัคร (`RegisterAsync`/SSO) **ไม่สร้างบริษัท** เมื่อคำเชิญถูกใช้อยู่แล้วก่อนรอบนี้ — ปัญหาอยู่ที่ UX/ทางเข้าอื่น (B2/B3) ไม่ใช่เงื่อนไขนี้
- `/api/company` (รายชื่อบริษัท) ไม่มี companyId ใน route ⇒ สมาชิกรอสิทธิ์ยังเห็นชื่อบริษัทในตัวเลือก (ตั้งใจ — สลับบริษัทได้)

## 4. เลื่อน / ข้อสังเกต
- เมนูอื่นที่ API ไม่ตรวจคีย์ `perm:*` (ส่วนใหญ่) ยังอยู่ใต้ "สิทธิ์เมนู" ของบทบาทตามเดิม — ไม่ผูกคีย์ที่ API ไม่ได้ตรวจ (ไม่แต่งกติกา)
- `simple.html` เรียก `reports/month-snapshot` ที่ไม่ตรวจ Reports.Dashboard (ตัวเลขรายรับ-จ่ายของเดือน) — หน้านี้ถูกซ่อน/พาออกแล้วเมื่อไม่มีสิทธิ์ แต่ endpoint เองยังไม่มีด่าน (backlog — ไม่แก้ในรอบนี้เพราะแตะ AccountingController ของทีมอื่น)
- `tools/required_call_site_check.py`: บล็อกกติกา `_R275C_` ของแพ็ก 275 C อยู่**หลัง** `if __name__ == "__main__"` ⇒ ไม่ถูกรัน (ไม่ได้แก้ — ไฟล์ทีมอื่น · แจ้งผู้ประสานงาน) · กติกา `_R277_` วางไว้ก่อน main
- รายการ "คำเชิญของฉัน" ในแอปสำหรับผู้ใช้ที่สมัครเองด้วยอีเมลเดียวกัน (ไม่ผ่านลิงก์) — ยังต้องเปิดลิงก์ในอีเมล (เลือกเพราะอีเมลที่ยังไม่ยืนยันไม่ใช่หลักฐานถือกล่องจดหมาย · 277-5)

## 5. สิ่งที่เจ้าของต้องทำหลัง deploy
1. ไม่มีขั้นตอนบังคับ — migration (`Round277Migration`) รันเองตอนบูต · คำเชิญที่ค้างอยู่ใช้ลิงก์เดิมได้
2. ผู้ใช้ที่เคยเห็นแดชบอร์ดโดยไม่มีสิทธิ์ ⇒ ตอนนี้เข้าหน้าแรกที่มีสิทธิ์แทน · ถ้าต้องการให้เห็นแดชบอร์ด ติ๊ก "ดูแดชบอร์ดภาพรวม" ในหน้าบทบาท (หรือใช้บทบาทนักบัญชี)
3. ตรวจว่าตั้งค่าอีเมลระบบแล้ว (ไม่งั้นหน้าทีมจะแสดงลิงก์ให้คัดลอกเอง)
