# รอบ 198 — Payment Gateway / Marketplace / OTA: เงินพักใน online wallet → โอนเข้าบัญชีตามรอบ หักค่าธรรมเนียม

ผู้ใช้: "ลูกค้าไปเปิด Payment Gateway หรือเคสที่เป็น Market Place รวมถึง OTA ต่างๆ เงินจะรับไปอยู่ที่ online wallet ก่อน และโอนเข้าบัญชี
ตามรอบ และมีหักค่าธรรมเนียม ค่าบริการต่างๆ ระบบรองรับในการจัดการ การลง JE ตรงนี้ครบถ้วนรึยัง ตั้งทีมที่เก่งทุกด้านขึ้นมาวิเคราะห์
ไล่กระบวนการทำงาน วางแผน พัฒนา ให้ครบสมบูรณ์ทุกขั้นตอน"

## ขอบเขตกรณี (ต้องครอบทุกกรณี)
- **Payment gateway** (Omise/2C2P/GB Prime Pay/Stripe/KBank/SCB): ลูกค้าจ่ายบัตร/QR → เงินพัก gateway → settlement รายวัน/รอบ หัก MDR + VAT ของค่าธรรมเนียม
- **Marketplace** (Shopee/Lazada/TikTok Shop/LINE MyShop): ขายผ่านแพลตฟอร์ม → รายได้ (ราคาเต็ม) → หักค่าคอมมิชชัน/ค่าธรรมเนียมชำระเงิน/ค่าขนส่ง/โปรโมชัน/ค่าบริการ
  → ถอนเข้าบัญชีตามรอบ · คืนเงิน/คืนสินค้า · ใบกำกับค่าธรรมเนียมจากแพลตฟอร์ม (ภาษีซื้อ) · หัก ณ ที่จ่ายค่าบริการที่เราจ่ายแพลตฟอร์ม?
- **OTA** (Agoda/Booking.com/Expedia/Trip.com/Traveloka): สองโมเดล — Merchant (OTA เก็บเงินแขก โอนสุทธิให้เรา) vs Agency (แขกจ่ายที่พัก
  เราจ่ายค่าคอมให้ OTA) · OTA ต่างประเทศ ⇒ ภ.พ.36 (VAT แทนผู้ประกอบการต่างประเทศ) · ภ.ง.ด.54 · สกุลเงินต่างประเทศ/อัตราแลกเปลี่ยน · VCC (virtual credit card)
- chargeback / dispute · เงินกันไว้ (reserve/holdback) · ยอดติดลบ (แพลตฟอร์มหักจากรอบถัดไป) · ค่าธรรมเนียมถอนเงิน · ภาษีขาย: ออกใบกำกับให้ลูกค้าปลายทางเมื่อไร (tax point)
- ทางเข้า: CSV/Excel settlement report · API (ถ้ามี) · statement ธนาคาร (เงินเข้าสุทธิ) · OCR ใบกำกับค่าธรรมเนียม
