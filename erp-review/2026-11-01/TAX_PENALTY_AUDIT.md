## 2. สิ่งที่ทำในรอบนี้ (ตัวตั้งเดียว)

- `Helpers/LatePaymentPenaltyPolicy` (pure) — `Suggest(type, งวด, ภาษี, วันจ่าย, วันหยุด)` คืนเงินเพิ่ม/เบี้ยปรับที่เสนอ + เหตุผล + คำแนะนำค่าปรับอาญา ·
  สูตรเงินเพิ่มเรียกตัวเดิม (`SsoLateFee` ม.49 · `RevenueCodeSurcharge` ม.27/ม.89/1 · `Pp36Lifecycle.SuggestedSurcharge`) — ไม่มีสูตรชุดที่สอง ·
  `Resolve(...)` = ค่าที่ผู้ใช้แก้ชนะ · ไม่ส่งเงินเพิ่ม = สปส./ภ.พ.36 ใช้ค่าเสนอ (พฤติกรรมเดิม) แบบอื่น 0 · ติดลบ = ปฏิเสธ · `AddBackTotal` = ยอดบวกกลับ
- `Helpers/PenaltyExpenseAccount` — ค่าตั้ง `CompanySettings.PenaltyExpenseAccountCode` → 54820 → 54xxx ชื่อเงินเพิ่ม/เบี้ยปรับ/ค่าปรับ → สร้าง 54820 ใต้ 548 · **เลิก fallback 58xxx**
- หน้านำส่งรวม: สามช่อง (เงินเพิ่ม · เบี้ยปรับ · ค่าปรับอาญา/อื่น ๆ) ทุกแบบ + ปุ่ม "คำนวณให้" (`/preview` เซิร์ฟเวอร์คิด) · ประวัติแสดงแยกก้อน · หน้าเงินเดือน: ช่องเงินเพิ่มแก้ได้
- ลงบัญชี: บรรทัด Dr ผังค่าปรับแยกต่อก้อน (คำอธิบายอ้างมาตรา + "รายจ่ายต้องห้าม §65 ตรี(6)") · Cr ธนาคาร = ภาษี + ทุกก้อน ·
  แถว `StatutoryRemittance` เก็บ `Penalty`/`OtherFine` + ค่าที่ระบบเสนอ (`SuggestedLateFee`/`SuggestedPenalty`) — แถวเดิม 0/NULL ไม่กระทบยอด

## 3. เปิดค้าง — ต้องให้เจ้าของ/ผู้ทำบัญชียืนยัน

1. ~~**ภ.ง.ด.50/51 ไม่มีเส้นชำระในระบบ**~~ → ✅ รอบ 228 ทีมภาษี (§5) — แบบ `CitPnd51`/`CitPnd50` ในหน้านำส่ง + §67 ตรี (ค่าเสนอ)
2. ~~**กองทุนเงินทดแทน** ไม่มีเส้นนำส่ง/เงินเพิ่ม~~ → ✅ รอบ 228 (§5) — แบบ `WcfAnnual` · เงินเพิ่ม ม.46 3%/เดือน (**ยังต้องยืนยันอัตรา** — §5 ต้องยืนยัน)
3. ~~**อากรแสตมป์** `MarkPaid` ไม่ลง JE~~ → ✅ รอบ 228 (§5) — `RemitStampDutyAsync` + เงินเพิ่มอากร ม.113/114 (ค่าเสนอ)
4. **ตารางเบี้ยปรับ ภ.พ.30 2/5/10/20%** (ยื่นเองช้า ≤15/≤30/≤60/>60 วัน) — **ต้องยืนยันเลขระเบียบกรมสรรพากรว่าด้วยการงดหรือลดเบี้ยปรับ** และใช้ได้เฉพาะยื่นเองก่อนถูกตรวจ/หมายเรียก · ช่องแก้ได้เสมอ
5. **ภ.พ.36 เบี้ยปรับ** — รอบ 228: ระบบ**เสนอ**ตารางลดชุดเดียวกับ ภ.พ.30 (API ไม่ลงเองเมื่อไม่ส่งค่า) · **ยังต้องยืนยัน**
6. **กติกาเสียสิทธิ์ขยาย e-Filing — ต้องยืนยันกับนักบัญชี**: จ่าย/ยื่นภายในวันขยาย = ไม่มีเงินเพิ่ม · พ้นวันขยาย ⇒ ระบบนับจากวันครบกำหนดตามกฎหมาย (วันกระดาษ 7/15) · ติ๊ก "ยื่นแบบกระดาษ" ⇒ วันกระดาษเสมอ (ฝ่ายค้านข้อ 1)
7. ค่าปรับอาญา (ม.35 ≤ 2,000 บาท ฯลฯ) ระบบ**ไม่เดา**ตัวเลข — กรอกตามหนังสือเปรียบเทียบปรับ
8. รอบเงินเดือนที่นำส่ง สปส. พร้อมเงินเพิ่มแล้ว **กลับรายการไปก่อนรอบ 220** ถูกล้าง JE id ไปแล้ว ⇒ ตัวบวกกลับหาไม่เจอ (migration เติมได้เฉพาะรอบที่ยังผูก JE) — ตรวจมือถ้าปีภาษีนั้นยังไม่ยื่น ภ.ง.ด.50

### คำตัดสินที่เลือก (ทิศอนุรักษ์ · แก้ได้บนจอ)
- ไม่รู้ทุน ⇒ ไม่ใช่ SME (Q10 เดิม) · ตัดสิน SME จาก **ทุนปัจจุบันในระบบ** (ไม่มีประวัติทุน ณ วันสิ้นรอบ) — ต่างได้ ⇒ ช่องกำหนดเอง + เหตุผล

- รอบแรก < 12 เดือน: ระบบไม่ยกเว้นเอง (ไม่มีวันจดทะเบียน · `Company.CreatedAt` = วันเริ่มใช้ระบบ) — ผู้ใช้ติ๊ก · ไฟล์ ภ.ง.ด.51 (`ExportPnd51Async`) ยังยกเว้นอัตโนมัติจาก `CreatedAt` (ค้าง: ยุบเป็นตัวตัดสินเดียว)
- ผลขาดทุนยกมา 5 ปี: ภ.ง.ด.50 ค่าตั้งต้น = ตัวตั้งเดียวกับรายงาน (ฝ่ายค้าน S4) · ภ.ง.ด.51 ไม่หัก (ประมาณการ — ต้องยืนยัน)
- ส่วนเกินค่ารับรองครึ่งปี = ค่าใช้จ่ายครึ่งปี − เพดาน(รายได้ครึ่งปี × 2) ÷ 2
- ภาษีถูกหัก: หนังสือรับรอง Received/Claimed ลงวันที่ในงวด · ไม่มีวันที่ ⇒ ไม่นับ + เตือน (ฝ่ายค้าน S5 — ภ.ง.ด.50 เดิมนับตาม `TaxYear` ⇒ เปลี่ยนตัวเลขของรายงานที่สร้างใหม่) · Pending ไม่นับ
- เงินทดแทนรายคน: ฐาน ปกส. ชนเพดาน ⇒ ใช้รายได้รวมงวด (อาจรวมรายได้ที่ไม่ใช่ค่าจ้าง ⇒ สมทบมากกว่า ไม่ใช่น้อยกว่า) · ยังคิดใหม่เฉพาะเมื่อฐาน ปกส. เปลี่ยน (แก้แค่รายได้ไม่คิดใหม่ — เดิม)

### ต้องยืนยันกับนักบัญชี (รอบ 230)
1. ตารางอัตรา SME ก่อนรอบบัญชี 2560 (ระบบใช้ 0/15/20 + คำเตือน) — ถ้ามีลูกค้ายื่นย้อนหลังก่อน 2560 ต้องเพิ่มแถว `CitRateBracket`
2. เกณฑ์ "รายได้ ≤ 30 ล." นับรายได้ประเภทใด (ระบบนับรายได้ทุกผัง) และทุนชำระ "ณ วันสุดท้ายของรอบ" (ระบบใช้ทุนปัจจุบัน)
3. ภ.ง.ด.51 §67 ทวิ(2) ของ SME — ใช้ขั้นบันไดครึ่งหนึ่ง (ระบบ) หรือขั้นเต็ม
4. เพดานค่ารับรองครึ่งปีสำหรับประมาณการ ภ.ง.ด.51 (ระบบใช้เพดานครึ่งหนึ่งจากรายได้ทั้งปีประมาณการ)
5. ตั้งหนี้ CIT ณ วันสิ้นงวดเมื่องวดปิดแล้ว — ระบบปฏิเสธ (ต้องเปิดงวด) · ถ้าต้องการลงเป็นรายการปรับปรุงงวดถัดไป ต้องตัดสินแนวทาง
6. เงินทดแทนรายคน ฐาน = MAX(ฐาน ปกส., รายได้รวมงวด) เมื่อชนเพดาน — รายได้บางประเภท (เช่น สวัสดิการ) ไม่ใช่ค่าจ้าง ม.5
7. (ฝ่ายค้าน) เครดิตภาษีถูกหักนับตาม "วันที่บนหนังสือรับรอง" ในรอบบัญชี — หรือวันที่ได้รับ/วันที่ถูกหัก
8. (ฝ่ายค้าน) ภ.ง.ด.51 หักผลขาดทุนยกมาในประมาณการหรือไม่ (ระบบไม่หัก)

### ตรวจตัวเอง 3 คำถาม (ไม่มี Agent tool ในรอบนี้ — ฝ่ายค้านเป็นการตรวจตัวเอง)
